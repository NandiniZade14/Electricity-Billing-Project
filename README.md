# Electricity-Billing-Project
The Electricity Billing System is a desktop-based application designed to automate the process of generating and managing electricity bills for customers.

This system eliminates manual work by providing a fast, reliable, and user-friendly interface for billing operations.

With the integration of AI-based consumption prediction and recommendation systems, the project not only automates billing but also helps forecast future electricity usage, offering valuable insights for both users and the electricity board.

The system uses JDBC (Java Database Connectivity) to connect Java with the MySQL database.

The project also includes a built-in Payment Gateway supporting full payments, EMI options, refunds, auto-debit setup, and automatic receipt generation, ensuring smooth and secure payment processing.
